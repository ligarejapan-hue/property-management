物件管理システム 使い方ガイド

不動産の物件・所有者情報の管理から、現地調査・販売図面づくり・DM営業までを、ひとつの画面でまとめて行える社内システムです。このページは、初めて使う方が「何ができて・どう使うか・いま何が準備中か」を一読で分かるようにまとめたものです。

対象: 社内スタッフ・関係者　／　運営: 株式会社リガーレジャパン　／　最終更新: 2026-08-16

01このシステムでできること

紙やExcel、外部ソフトに分かれていた「物件の情報」「現地のメモ」「販売チラシ」「営業DM」を、ログインひとつで扱える一箇所に集めたものです。下の7つが主な柱です。

🏢

物件・所有者の管理

土地／マンション／戸建／一棟の情報と、所有者・連絡先を一元管理。一覧・検索・CSV出力も。

🗺️

現地調査（スマホ）

「撮って登録」でその場で撮影→ピン登録。地図に写真やメモを残し、巡回の履歴も確認できます。

🖼️

販売図面づくり

売り出しの「1枚チラシ（マイソク）」をシステム内で作成し、PDF・画像で出力。

✉️

営業DM支援

宛名の出力から送付の記録・反響・再送候補まで。売却提案の文面はお手元のAIで作って貼り付けます。

📥

データ取り込み

受付帳CSVや謄本PDFを読み込んで、物件・所有者情報に反映。

🛡️

管理者機能

ユーザー・権限の管理、操作の記録（監査ログ）、データ品質のチェック。

🌙

使いやすさ

明るい／暗い表示の切替、スマホ対応、個人情報の保護に配慮した設計。

02機能の説明（分野べつ）

それぞれの分野で「何のためのものか」を、専門用語をなるべく避けて説明します。

🏢物件と所有者の管理

システムの土台です。物件の所在地・面積・用途地域・接道などの基本情報と、その所有者（個人・法人）をひも付けて保存します。

  • 物件一覧から種別や条件で絞り込み、詳細画面で「基本情報／所有者／写真／調査情報」をタブで確認
  • 新規登録・編集・削除、まとめてのCSV出力、DM差込用のCSV出力
  • 法人の所有者は「法人番号（会社法人等番号）」を手がかりに名称を照合・補完
  • 所有者の「現住所」：取り込んだ住所は登記上のものです。引っ越して登記を変えていない方のために、住所欄の横のボタンで「登記上の住所」と「現住所」を分けて持てます。DMの宛先は現住所を優先します（空なら登記上）
  • 物件名の欄：一棟アパート／一棟マンション／区分マンションのときだけ「物件名（任意）」が出ます。区分マンションの販売図面の「建物名称」に入ります
個人情報（氏名・住所など）は、画面や記録に不用意に出さないよう保護のしくみを入れています。
⚠宛名の並べ方が1つ変わりました（2026-08-13）：同じ住所で郵便番号だけが違う共有者は、これまで2通に分かれていましたが、1通にまとまります（同じ場所へ2通届くのを防ぐため）。

🗺️現地調査（スマホで現場記録）

現場に出たとき、地図の上に「調査ピン」を立てて写真やメモを残せます。担当者がどこを回ったかの巡回記録にもなります。

  • 地図の「🚶 巡回を開始」ボタンから2タップで巡回開始。巡回中は「位置記録中（緑）／準備中（青）」などの状態が色つきチップで分かります
  • 巡回なしで撮影：許可された人は、巡回を開始せずに「📷 撮って登録」でその場から1タップで撮影・登録できます（種類は「物件化候補」で固定）。移動ルートは残らないため、担当エリアを見て回るときは今までどおり巡回ボタンを押す運用にしてください
  • 「📷 撮って登録」ボタンで、撮影→保存だけでピンと写真を一度に登録。保存後もそのまま次のピンを続けて立てられます
  • ピンは種類ごとに色分け（物件化候補＝緑・要確認＝琥珀・調査不可＝紫・再確認＝青）。対応済みは灰色の✓になり、「対応済みを隠す」こともできます
  • 「物件化の完成待ち」一覧で、あとで物件にする候補をまとめて確認。写真を見る・地図で見る・候補から外す、もここからできます
  • 住所の自動入力（新）：撮った場所を物件にするとき、「ピンの位置から住所を入力」を押すだけで住所欄が埋まります。東京・神奈川・千葉・埼玉は、住居表示（○番○号）のデータがある場所なら号まで入ります（例：東京都杉並区西荻北3-19-4）。データが無い場所は番まで、または町名・丁目までとなり、どこまで入ったかは押したあとの案内文に出ます
  • 歩いた場所の色（新）：地図に「歩いた場所」を色で重ねられます。何人が・何日にわたって通ったかが多いほど濃くなり（1人が同じ日に何度通っても1回）、二度歩きを避けられます。色が付くのは「巡回終了」の後です。「歩いた道筋（線）」も併用できます
  • 巡回開始が1本に（新）：「巡回を開始」を押すだけで、位置の記録開始・現在地への移動・建物が見える倍率までまとめて済みます
  • ピンを立てる場所は地図をタップして指定します（写真だけ先に撮って、あとから場所を指すこともできます）
  • iPhoneの写真（HEIC形式）や大きな写真も、多くの場合は自動変換でそのまま保存できます（変換できないときは画面に対処方法の案内が出ます）
  • 撮影した写真は、保存時に位置情報（GPS）を自動で取り除きプライバシーに配慮
⚠ スマホで使うときの注意：「現在地（GPS）」は安全な接続（HTTPS）でアクセスしたときだけ使えます。社内で配布している安全なアドレス（https で始まるもの）から開いてください。数字だけのアドレス（http で始まるもの）で開くと位置情報が拒否され「⚠位置記録エラー」と表示されます（故障ではありません）。その場合も写真の撮影・保存はできますので、場所は地図をタップして指定してください。

🖼️販売図面（マイソク）づくり

物件を売り出すときの「1枚チラシ」を、外部ソフトを使わずシステム内のエディタで作れます。物件情報から下書きが自動生成され、あとは自由に整えて出力します。

  • 種別ごとのひな形（売土地／売マンション／売戸建／一棟）から作成
  • 写真をギャラリーから追加、位置やトリミングの調整、「写真を自動整列」で大小を組み合わせたモザイク配置（タイル状）に隙間なく並べられます
  • 2列・3列の段組みレイアウト、交通・面積などの概要表の編集、やり直し（undo/redo）に対応
  • 「新着」などのオリジナルバッジ、QRコード（物件ページ用・地図用）、図面全体のフォント・基調色の変更
  • 文字や表が重なったときは琥珀色の警告でお知らせ。できあがりはPDF・画像（PNG）で出力（見たままが出力されます）
会社情報（社名・免許番号など）は管理者メニューの「会社情報」で設定でき、図面下部の会社帯に反映されます。

✉️営業支援（DMの送付管理・売却促進DM）

所有者へ送るお手紙について「宛名を出す → 送ったことを記録する → 返事を記録する → 頃合いを見て送り直す」までを扱えます。
⚠出し方は2通りあり、どちらか一方を選びます（両方行うと同じ方へ二重に送ることになります）。A＝宛名CSVだけ出して封筒等で送る／B＝売却提案の手紙をシステムで作って印刷する。送った記録と反響は、どちらも同じ「DM送付履歴」に残ります。

  • 宛名CSVの出力は2段階：出力すると「控え」ができ、投函したら「送付の確定」で投函日を入れて記録に変えます。実際に出した相手にだけ記録が付きます
  • 反響の記録：物件の「DM送付履歴」に、反応なし／連絡あり／拒否／宛先不明を記録できます。「宛先不明」にすると、その物件のDM可否が自動で「送らない」に変わります
  • 断られた相手を自動で外す：拒否・宛先不明が付いた所有者は次から宛名CSVに入りません（その方が持つ別の物件も含めて外れます）。除外した件数は必ず画面に出ます。⚠売却DM（手紙をシステムで作る方）にはこの自動除外がまだ入っていません（2026-08-16時点）。対象を選ぶ前に「DM送付履歴」で拒否・宛先不明の有無をご確認ください（開発側で対応予定）
  • 再送候補：物件一覧の「再送候補のみ」で、前回の送付から一定期間が過ぎ、拒否・宛先不明・連絡ありが無い相手だけに絞れます
  • 売却促進DMの文面：システムが指示文（プロンプト）だけを作り、それをお手元のブラウザのAI（ChatGPT等）に貼って文面を作り、戻ってきた文章を貼り付けて保存 →「この型の全宛先に適用」→確定 → 印刷 → 確定分を送付済みに、という流れです（印刷されるのは確定済みだけ。「送付済みに」まで進めると反響を記録できるようになります）
AIに自動で書かせる機能は廃止しました（2026-08-14）。システム側では費用が発生しません。⚠ただしお使いになるAIサービス側の料金は、そのサービスの契約によります（有料プラン・従量課金だと費用がかかることがあります）。会社として使ってよいサービスかを事前にご確認ください。無料の範囲でも同じ手順で作れますし、ご自身で文章を書いても構いません。指示文には所有者名・住所・物件の情報を一切入れていません（渡せない作りです）。お手元のAIにも個人情報は入力しないでください。
本文に {{物件所在}} / {{物件種別}} と書くと宛先ごとに差し込まれます（所在は町名までで番地は載りません）。この2つ以外の記号は保存できません。
1通でも「確定」した型は文面の設定（トーン・長さなど）を変えられません（変えたいときは新しい型を追加してください）。

📥データの取り込み

手入力を減らすため、既存の資料を読み込んで物件・所有者情報に反映します。

  • 受付帳のCSV取り込み
  • 謄本（登記情報のPDF）の取り込み
  • 登記情報からのDM宛先取り込み（所有者事項PDFのフォルダごと一括取り込み→宛先作成まで一気通貫。フォルダ一括はこの画面だけの機能です）
  • 取り込みの見える範囲（新）：取込履歴は自分が実行した分だけが表示されます（管理者は全員分）。ほかの人の取込を見せたい場合は、管理画面の「インポート」で「全員分の閲覧」を、取り消しなどの操作も任せる場合は「他の人の分も編集」を付けてください
不動産番号が分からない物件でも、「所在で謄本を検索」で候補を自動で探せます。検索中は自動操作の様子が小窓（実況パネル）で見られます。利用できるのは登記情報サービスの提供時間内（平日8:30〜23:00・土日祝8:30〜18:00）です。外部サービスの操作は有料になり得るため、実行前に確認画面が出ます。候補から書類そのものを取得する機能（有料）は組み込み済みですが、いまは「準備中」の状態で止めてあります（一覧に「候補からの謄本取得（有料）は現在準備中です。」と出ます）。実際に1件取得して確かめる作業を行ってから開放します。

🛡️管理者向け機能

システムを安全に、データをきれいに保つための機能です（管理者メニュー内）。

  • ユーザー管理・権限テンプレート・パスワード変更・会社情報の設定
  • 監査ログ（誰がいつ何をしたかの記録・日本語表示）・権限変更履歴
  • データ品質チェック（所有者補正候補・法人番号紐づけ・表示名監査・郵便番号×住所チェック・テキスト衛生監査・氏名・連絡先チェック）・添付検索
  • 安全のための自動ログアウト（1時間操作がないと自動でログアウトします）

03使い方（基本の流れ）

はじめての方向けに、よく使う操作の流れをまとめました。左上の「≡（メニュー）」から各画面へ移動できます。

はじめてのログイン

  1. 配布されたURLを開き、ユーザー名とパスワードでログインします。
  2. ログインすると、役割に合わせたホーム画面が表示されます（現場担当なら調査系、事務所なら物件系の入口が先頭に並びます）。右上で表示テーマ（明／暗）を切り替えられます。
  3. 使える機能は権限（管理者・一般など）によって変わります。見えない項目がある場合は管理者にご確認ください。
  4. 1時間操作がないと、安全のため自動でログアウトします。入力の途中はこまめに保存しましょう。

物件を探す・見る

  1. メニューから「物件一覧」を開きます。
  2. 「絞り込み」で種別や条件をしぼって目的の物件を探します。
  3. 物件カードをタップすると詳細画面へ。タブで基本情報・所有者・写真・調査情報を確認できます。

物件を登録する

  1. 物件一覧の「＋ 新規物件登録」を押します。
  2. フォームに所在地などを入力して保存します（あとから編集も可能）。
  3. 必要に応じて所有者を紐付け、写真を追加します。

販売図面（チラシ）をつくる

  1. 物件の詳細画面で「販売図面を作成」を押します。
  2. 不足している項目（価格・交通など）を入力すると、下書きが自動で作られエディタが開きます。
  3. 写真の追加・自動整列、バッジやQRの配置、文字や色を整えます。
  4. 「保存」してから「PDF出力」または「PNG出力」でチラシを書き出します。

現地調査をする（スマホ）

  1. メニューから「現地調査マップ」を開き、地図の「🚶 巡回を開始」を押します。
  2. 現場に着いたら「📷 撮って登録」で撮影→保存。ピンと写真が一度に登録され、そのまま次の現場でも繰り返せます。
  3. 終わったら「巡回終了」。記録は「巡回履歴」で、あとで物件にする候補は「物件化の完成待ち」で確認できます。
    「物件化の完成待ち」から物件にするとき、「ピンの位置から住所を入力」を押すと住所が自動で入ります（1都3県は住居表示のある場所なら号まで、無い場所は番まで／町名・丁目まで）。どこまで入ったかは画面の案内文に出るので、そのとおり保存前に住所を目でご確認ください。

04いまの状態と、残っている作業

機能ごとの状態を4段階で色分けしました。「まもなく」「設定待ち」「これから」が残タスクです。

✅ 稼働中 🔷 まもなく（開発完了・反映待ち） ⚙️ 設定待ち（機能はあるが未有効化） 📋 これから・検討中

✅ 稼働中

  • 物件・所有者・棟の管理一覧・検索・登録・編集・CSV出力に加え、住所の自動補完（郵便番号から）も稼働中。
  • 販売図面エディタ4種のひな形・写真管理（自動整列＝モザイク配置）・概要表の編集・段組み・バッジ・QR（物件/地図）・重なり警告・PDF/PNG出力まで利用可能。会社情報の設定も反映されます。
  • 現地調査（カメラファースト運用）地図の「巡回を開始」→「撮って登録」の最短動線、ピンの色分け、完成待ち一覧（写真・地図・候補から外す）、巡回履歴まで一通り稼働。許可した人は巡回なしで1タップ撮影も可能（管理画面で個別に付与）。巡回開始は1本化され、押すだけで位置記録・現在地移動・倍率調整まで済みます。歩いた場所の色（踏破ヒート）と道筋の線も稼働。
  • 住所の自動入力撮った場所を物件にするとき、ボタン1つで住所欄が埋まります。東京・神奈川・千葉・埼玉は住居表示のデータがある場所なら号まで（例：東京都杉並区西荻北3-19-4）、無い場所は番まで／町名・丁目まで。どこまで入ったかは画面の案内文に出ます。まず社内に取り込み済みの国の無料データで照合し、そこに無い場所ではピンの緯度・経度だけを国土地理院（国の機関）に送って町名・丁目までを調べます（氏名や物件の情報は送りません）。どちらも無料で、追加費用はかかりません。
  • 謄本の所在検索（候補一覧まで）住所から候補を自動検索。実況パネル（自動操作の様子が見える小窓）と中止ボタンつき。提供時間内のみ（平日8:30〜23:00／土日祝8:30〜18:00）。2026-08-15に実機で動作確認済み（丁目のある住所・ない住所の両方で候補が出ました）。⚠実行前に「有料処理になり得ます」という確認が出ます。候補探しの段階で料金が発生したことはこれまでありませんが、料金の扱いはサービスの規定によります。書類そのものの取得（有料）は「準備中」で止めてあります。
  • 謄本まわりの整理物件ページの謄本のボタンは「所在で謄本を検索」の1つだけになりました（不動産番号で引くボタンは、押しても必ず失敗する状態だったため撤去）。取得前には「取得済み・所有者入力済み」の警告と、土地／建物のどちらを取りに行くかが出ます。書類の種類は所有者事項／全部事項から選べます。
  • 地番・家屋番号の確認導線土地の登記は地番、建物の登記は家屋番号で引きます（住所の番号＝住居表示とは別物）。⚠家屋番号は地図では分かりません（権利証・固定資産税の通知・過去の謄本などでご確認ください）。以下は地番の調べ方です。地番が空の物件では、住所をコピーできる画面と「登記情報提供サービスを開く」ボタン（ログイン画面）が出ます。地図はサービスの中の「地番検索」から開き、読み取った地番をアプリに戻して保存 → そのまま取得の確認へ進めます。
  • 巡回の自動終了終了ボタンを押し忘れても、1時間なにも操作がなければ自動で終了します（2026-08-15 稼働）。終了時刻は「最後に操作した時刻」に戻すので、放置していた時間は巡回時間にも歩いた場所の色にも入りません。
  • DMの送付管理（記録・反響・再送候補）宛名CSVは「出力＝控え」→「送付の確定＝投函日を入れて記録」の2段階。反響（反応なし／連絡あり／拒否／宛先不明）を記録でき、拒否・宛先不明の方は次から宛名に入りません（その方の別物件も含む）。「再送候補のみ」で送り時の相手だけに絞れます。

05安全とデータの守り方（管理者向け）

観点やっていること
権限役割（管理者・一般など）ごとに使える機能・見える情報を制限。テンプレートで一括管理。
個人情報氏名・住所などを画面や記録に不用意に出さない保護。写真は保存時に位置情報を自動除去。
操作の記録誰がいつ何をしたかを監査ログに記録。権限変更の履歴も保持。
バックアップデータベースを毎日自動でバックアップ（世代管理・暗号化準備あり）。遠隔地保管は準備中。
監視システムの生存確認を定期実行。異常はログに記録。
お掃除不要になった添付ファイルを猶予期間ののち自動で整理。
