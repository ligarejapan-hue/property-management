# 取引・帳票 段4後半(事業計画書の発行=PDF・Excel)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 事業計画書(社内用・銀行向け)を、資金計画表と同じ発行の道で PDF と Excel(数式入り)にし、発行履歴(書類タブ)に残す。

**Architecture:** 書類の一覧 `DEAL_DOC_TYPES` に `business_plan`(社内用/銀行向け)を足す。発行 API は書類の種類ごとに「保存済みの入力 → 計算と HTML → Excel」を選ぶだけにし、保存・版・権限・後片付けは段3のまま。Excel は資金計画表の書き方(`Writer`)を共通の部品に出して使う。

**Spec:** `docs/superpowers/specs/2026-10-23-deals-documents-design.md`(§4.7〜4.9・§6 段4)+ 依頼書 4.2・6。段4前半の計画 `2026-10-24-deals-phase4a-business-plan.md` の読み替え 1〜14 をそのまま使う。

## Global Constraints

- DB の変更なし・新しい部品なし。
- Excel は合計・粗利・利益率を数式で入れ、どの数式のセルにもサーバーの値を結果として入れる(設計 §4.8)。
- 画面・PDF・Excel で同じ「出すセクション」を使う。銀行向けに承認欄・社内メモを出さない。
- 事業計画書は買取再販の取引だけ(発行も 422 `NOT_RESALE`)。

## 読み替え(Rulings)

1. **Excel の数式:** 各セクションの合計 `SUM`、仕入・販売の税抜 `税込−建物消費税`、借入金利息 `ROUNDDOWN(借入額×年利(整数)×日数/3650000,0)`、経費合計 `仕入価格+出すセクションの合計`、粗利 `売上−経費合計`、利益率 `TRUNC(粗利*10000/売上)/10000`(サーバーの 0.01% 切り捨てと同じ・読み替え 6)、損益分岐 `=経費合計`、NOI `収入−運営費`、利回り `TRUNC(…*10000/…)/10000`。固都税・管理費等の日割りは値で入れる(日数の端数の決まりをサーバー1か所に置く)。
2. **売上が無い・日付が揃わないときは数式を入れず空欄**(サーバーの計算も空)。
3. **Excel の共通部品:** 資金計画表の `Writer`・`amountLines`・`sumOf` を `documents/xlsx-writer.ts` に出す(資金計画表の Excel は変わらない=既存のテストで確かめる)。テストの数式の評価器も `__tests__/xlsx-eval.ts` に出し、`TRUNC` を足す。
4. **画面:** 事業計画書の画面に「保存して発行(PDF・Excel)」。発行の結果の出し方は資金計画表と同じ(上に「第○版を発行しました」と PDF・Excel のリンク)。書類タブに「事業計画書を作る・発行する」(買取再販の取引だけ)。
5. **版の番号は (取引, 事業計画書, 社内用/銀行向け) ごと**(段3の決まりのまま)。
6. **(最終レビューで追加)Excel の割り算・率の掛け算は整数にしてから行う。** 利益率・利回り `TRUNC(分子*10000/分母)/10000`、利息 `ROUNDDOWN(借入額*ROUND(年利*10000,0)*日数/3650000,0)`。理由: 小数のまま割ると、割り切れる値(例 0.29%・利息 2,100円)が Excel で 1 つ下に切り捨てられ、PDF と食い違う(0.01%〜99.99% のうち 573 通りで起きることを確かめた)。

## Review Focus

1. 銀行向けの PDF・Excel に承認欄・社内メモが入らない。
2. 仲介の取引で発行できない(422・ファイルも記録も残らない)。
3. Excel の数式を計算し直した値がサーバーの値と一致する(利益率・利回りの切り捨てを含む)。
4. 表で外したセクションが Excel にも無く、経費合計の数式にも入らない。
5. 資金計画表の発行が変わらない(共通部品に出したあとも同じ Excel)。
