# 取引・帳票 段4前半(事業計画書の計算・入力・画面・プレビュー・種別×セクションの表)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 買取再販の取引で、事業計画書(社内用・銀行向け)の入力・計算・プレビューができ、出すセクションを「物件種別×セクション」の表(取引の設定)で決められる。

**Architecture:** 入力は `plan_inputs.business` に保存(資金計画表と同じく、そこだけ差し替える)。計算は純関数 `businessPlanCalc(deal, dealCalc, inputs, rateRows)`。出すセクションは純関数 `businessPlanSections(kindKey, hasOc, variant, matrix)` で決め、画面・プレビュー(のちの PDF・Excel も)で同じものを使う。HTML は資金計画表と同じ `documents/html.ts` の自動エスケープで組む。

**Tech Stack:** Next.js 16, Prisma 7, zod 4, vitest 4

**Spec:** `docs/superpowers/specs/2026-10-23-deals-documents-design.md`(§2.4 種別×セクション・§4.8・§5 事業計画書・§6 段4)+ 依頼書 4.2(セクションの表)

## Global Constraints

- DB の変更なし(`plan_inputs`・`deal_settings.section_matrix` は段1で作成済み)。新しい部品なし。
- 金額は整数の円。端数は関数ごとに明記(この段はすべて円未満切り捨て)。
- 事業計画書は**買取再販の取引だけ**(仲介の取引では出さない)。
- 社内用=承認欄(担当/上長/決裁者)と社内メモを出す。銀行向け=承認欄・社内メモを出さない。
- 種別×セクションの表は設定で管理し、画面・PDF・Excel で同じものを使う。
- テストは架空データだけ。前職の文面は使わない。

## 読み替え(Rulings)

1. **段4を前半・後半に分ける。** 前半=計算・入力・画面・プレビュー・種別×セクションの表。後半=PDF・Excel(数式入り)の発行と書類タブへの追加。理由: 段3と同じ。計算と画面だけでも面が広い。
2. **種別×セクションの表は「出してよいか」だけを持つ。** 「銀行向けだけ」「OCありだけ」は表ではなく決まりとして重ねる(表で銀行向けの資金計画を社内用に出す、はできない)。初期値は全部オン、ただし土地は改装・工事をオフ。表に無い種別(あとで足した種別)は、その元の種別の行を使う。
3. **仕入価格 = 取引の売買価格。** 建物消費税は段2の按分(手で直した値があればそれ)。税抜 = 税込 − 建物消費税。
4. **販売の建物消費税は、仕入と同じ家屋割合で按分する**(評価額の表と土地割合をそのまま使う)。手で直す欄を付ける。
5. **仲介手数料(仕入・販売)は手入力。** 「上限額を入れる」ボタンで、その価格の上限額(税込)を入れられる(仕入は相手方に仲介が入らないこともあるため、自動では入れない)。
6. **印紙は売買契約書の表で自動。** 全額/折半は資金計画表と同じ選び方(事業計画書の入力に持つ)。
7. **登記費用は取引の「登記費用」、精算金は段2の決済の計算の「買主→売主」の差引(自社が払う分)。** どちらも手で直せる欄を付ける。
8. **事業期間 = 取引の決済日 〜 販売予定日(入力)の日数(両端を含む)。** 決済日か販売予定日が無ければ保有コストは 0 とし、足りない項目に出す。
   - 借入金利息 = 借入額 × 年利 × 日数 ÷ 365(円未満切り捨て)。
   - 固都税 = (固定資産税+都市計画税の年額) × 日数 ÷ 365(切り捨て)。
   - 管理費等 = (管理費+修繕積立金+その他の月額) × 12 × 日数 ÷ 365(切り捨て)。
9. **収支:** 経費合計 = 仕入価格 + 取得経費 + 改装・工事 + 保有コスト + 販売の費用。粗利 = 売上 − 経費合計。利益率 = 粗利 ÷ 売上(0.01% 単位・切り捨て)。損益分岐の販売価格 = 粗利が 0 になる売上 = 経費合計(販売の費用は今の売却価格のときの額で計算する、と画面に書く)。
10. **坪単価 = 価格 ÷ 坪数(切り捨て)。** 坪数 = 面積㎡ × 0.3025。面積は区分=専有面積、それ以外=土地面積。面積が無ければ出さない。
11. **OC収支:** 年間賃料収入 = OC の各部屋の(賃料+共益費+駐車場+その他)× 12。表面利回り = 年間収入 ÷ 仕入価格。NOI = 年間収入 − 年間の運営費(入力・既定は固都税の年額+管理費等の年額)。NET利回り = NOI ÷ (仕入価格+取得経費)。どちらも 0.01% 単位で切り捨て。入居者の状況 = 部屋数・賃借人のいる部屋数・滞納の部屋数と額。
12. **画面は買取再販の取引だけに出す**(仲介の取引ではボタンを出さず、道も 422)。
13. **社内メモ・承認欄は社内用だけに出す。** 承認欄は空欄の枠(押印のため)。

## Review Focus

1. 銀行向けに社内メモ・承認欄が出ない(HTML の文字列で確かめる)。
2. 表でオフにしたセクションが画面・プレビューの両方で出ない。足した種別は元の種別の行を使う。
3. 決済日・販売予定日・面積・価格が無いときに NaN や「undefined」が出ない。
4. 仲介の取引で事業計画書を出せない。
5. 計算の端数(利息・固都税・管理費・利回り・坪単価)が明記どおり切り捨て。
