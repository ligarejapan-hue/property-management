# 取引・帳票 段5b(委任状・鍵受領書・OC の4種)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 段5a の業務書類の一覧表に、委任状・鍵受領書と、OC ありの取引だけに出す4種(仕入相談表・賃借人属性調査書・賃貸人変更のお知らせ・引継書類チェックリスト)を足す。

**Architecture:** 書類ごとに組み立ての関数を1つ(`src/lib/deals/documents/business/`)と、一覧表 `registry.ts` の1行を足す。発行の道・出す前の確認・書類タブは段5aのものを使い、発行のときに選ぶもの(委任者・受任者・委任内容・鍵の行・変更日・振込先)を確認の小窓に足す。

**Spec:** `docs/superpowers/specs/2026-10-23-deals-documents-design.md` §4.1〜4.4・§4.7〜4.9 + 依頼書 4.3。

## Global Constraints

- DB の変更なし・新しい部品なし。
- 署名・実印の欄は常に空欄。委任状・鍵受領書・お知らせは明朝、表の書類はゴシック(設計 §4.2)。
- 業務書類の Excel は値だけ。監査には書類の種類・版だけ。
- 金額・利回りは段2・段4の計算の値をそのまま使う(書類の中で計算し直さない)。
- テストは架空データだけ。前職の文面は使わない。

## 読み替え(Rulings)

1. **委任状:** 委任者は売主・買主のうち自社でない当事者から1人選ぶ(初期値=最初の売主、いなければ最初の買主)。受任者は自社(会社名・代表者)か、当事者の「代理人」から選ぶ(初期値=自社)。委任内容は決まった項目(固定資産評価証明書の取得・売買代金の決済に関する一切の件・残代金の受領・鍵の受け渡し)にチェックを付け、自由な1行を足せる。1つも無ければ発行できない(422)。委任者の署名・実印の欄は空欄。日付は選べる(空なら空欄で出す)。
2. **鍵受領書:** 鍵の行(鍵の番号・種類と本数)を発行のときに入れる(1〜30行)。受領者は買主の当事者か自社(初期値=自社の買主がいれば自社、なければ最初の買主)。宛先は売主。受領者の署名・押印の欄は空欄。行が無ければ発行できない(422)。
3. **仕入相談表:** 段4の事業計画書と同じ OC 収支の計算(`businessPlanCalc(...).oc`)を使う。部屋ごとの行には賃借人の名前を出さず「入居中/空室」だけにする(社内の相談用で、名前は要らないため)。
4. **賃借人属性調査書:** 賃貸条件の行ごとに1つの欄。賃貸条件から写せるもの(部屋・賃借人・契約形態・期間・賃料・敷金・滞納・管理会社)を入れ、勤務先・連絡先・保証・入居人数・反社会的勢力の確認(□該当なし □要確認)・確認日・確認者は手で書く空欄にする。
5. **賃貸人変更のお知らせ:** 賃借人のいる部屋ごとに1枚(空室は出さない)。宛先は賃借人。新しい賃貸人=買主。変更日の初期値=決済日(日本時間)。賃料の振込先の初期値は、買主が自社なら取引の設定の口座、それ以外は空欄。売主・買主の連名で、押印の欄は空欄(自社の角印も付けない=署名・実印の欄は常に空欄の原則)。賃借人がいなければ発行できない(止める項目)。
6. **引継書類チェックリスト:** 部屋ごとの「賃貸借契約書(原本)・鍵・敷金」と、全体の「管理会社への連絡・敷金の引継ぎ(合計と相殺/別途)・賃料の振込先の変更の通知・滞納の確認・保証会社への連絡」。チェック欄は売主・買主の2列で空欄。最後に確認者の欄。
7. **発行のときに選ぶ「当事者から選ぶもの」は、一覧表の `defaults` に `choices`(欄の名前ごとの選べる値)として持たせ、出せる書類の API でそのまま返す。** 領収書の `issuers` はそのまま残す。
8. **書類タブは書類をまとまりで分ける:** 決済の書類/そのほかの書類(委任状・鍵受領書)/OC の書類。一覧表の各行に `group` を持たせる。

## Review Focus

1. 委任状・鍵受領書・お知らせの署名・押印の欄が空欄で、自社の角印が付かない。
2. OC の4種が OC なしの取引に出ない。
3. 当事者でない ID・自社を委任者に選べない(422)。
4. お知らせが賃借人のいる部屋の数だけのページになる(空室は出さない)。
5. 仕入相談表の利回り・NOI が事業計画書と同じ値。
